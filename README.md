# MCP Workshop

A complete hands-on guide to Model Context Protocol (MCP).

## Quick start

1. Set up each project separately — each has its own README
2. Run mcp-demo first to build the vector store
3. Run mcp-visualizer to see the live flow in the browser

## Projects

### mcp-demo
Core MCP implementation — ingest docs, run MCP server,
test with Inspector, query with Claude client.
See [mcp-demo/README.md](mcp-demo/README.md)

### mcp-visualizer
Streamlit app that shows the live MCP interaction flow
as a sequence diagram in the browser.
See [mcp-visualizer/README.md](mcp-visualizer/README.md)
